**ហានិភ័យ Emoji:** រូបរាងខុសគ្នាតាមឧបករណ៍ (Android ចាស់ អាចបង្ហាញជាប្រអប់ទទេ)។ គំរោង: ប្តូរ emoji នៃ **វិធីបង់ប្រាក់, ប៊ុតុង, theme, ស្ថានភាព** ទៅជា SVG icon (ក្នុង Sprint 1–2)។ រូបទំនិញ (🍚 ...) រក្សាជា emoji ព្រោះអ្នកប្រើជ្រើសបាន។

### Icon ថ្មីដែលត្រូវបន្ថែម (គំរោង)
`wallet` (សាច់ប្រាក់) · `qr` (KHQR) · `phone-pay` (Wing/Pi Pay) · `book` (ជំពាក់) · `print` · `download` (Backup) · `upload` (Restore) · `sun` · `moon` · `edit` · `check` · `x` · `warning`។ ដាក់ឯកសារក្នុង `assets/icons/` និង `icons.js`។

|---|---|---|---|
| **Plus Jakarta Sans** | លេខ អក្សរអង់គ្លេស (ជាមុន) | 400 · 500 · 600 · 700 | Google Fonts (`index.html`) |
| **Noto Sans Khmer** | អក្សរខ្មែរ (ជំនួសតាមតួអក្សរ) | 400 · 500 · 600 · 700 | Google Fonts (`index.html`) |
| system-ui · Segoe UI (បម្រុង) | ពេល font មិនទាន់ផ្ទុក | — | ក្នុងឧបករណ៍ |
| ui-monospace · Menlo · Consolas | លេខកូដ | — | ក្នុងឧបករណ៍ |

Tokens: `--font-latin` · `--font-khmer` · `--font-ui` · `--font-mono` (ក្នុង `css/tokens.css`)។ កម្ពស់បន្ទាត់ខ្មែរ ≥ 1.6 (មិនឱ្យកាត់ជើងអក្សរ)។ មាន weight `--fw-regular/medium/semi/bold`។
Icon font: **គ្មាន** (ប្រើ SVG ក្នុងបន្ទាត់ទាំងអស់)។

**គំរោង self-host:** ទាញយក ៨ ឯកសារ .woff2 ដាក់ក្នុង `assets/fonts/` (ឃើញ `assets/fonts/README.md`) ដើម្បីឱ្យ POS ដំណើរការពេល offline ហើយលុប `<link>` Google Fonts។

## ៤. ច្បាប់ពេលបន្ថែមថ្មី
- Icon ថ្មី: ឯកសារ `.svg` + បន្ថែមក្នុង `icons.js` + បន្ថែមជួរក្នុងតារាងខាងលើ + ពិនិត្យក្នុង `preview.html`។
- Font ថ្មី: ពិភាក្សាក្នុងក្រុមមុន (ទំហំឯកសារ, license) · ប្រើតែ license ដែលអនុញ្ញាតចែកចាយ (OFL/Apache)។
- កុំប្រើពណ៌ដោយផ្ទាល់ក្នុង SVG — ប្រើ `currentColor`។
- Emoji ថ្មី: សាកល្បងលើ Android ចាស់ និង Windows ជាមុន។
